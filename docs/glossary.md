# 詞彙表

- **草稿**：唯一可編輯的目前日報，保存在 `live_report_draft`。
- **定稿快照**：日報定稿時建立的不可回寫副本，含輸出文字與模板版本。
- **記憶**：供下一次填報建議使用的主檔資料，不是歷史日報內容。
- **候選記憶**：由現場輸入自動學習、尚未審核的資料；不出現在一般建議清單。
- **正式主檔**：人工新增或已確認的記憶，可作為下一次填報建議。
- **記憶審核**：確認候選為正式主檔，或逐筆駁回並依關聯規則處理目前草稿的流程。
- **材料主檔**：材料類型與候選欄位的可重用資料。
- **獨立進料**：可單獨輸出或連接到一個工種的進料原始記錄。
- **連接進料**：仍由獨立進料持有、但在指定工種輸出的進料。
- **官方模板**：目前唯一版本化的日報文字輸出規則。
- **收合摘要**：施工日報中固定 60px 的資訊列；包含填報資訊、四個日報頁籤的條目摘要與底部日報預覽。展開後只增加內容區，不改變摘要列高度。
- **條目摘要**：四個日報頁籤共用的收合摘要，含左側灰色類型區、左對齊兩列內容與第二列最右狀態膠囊；視覺上為連續卡面，不建立額外空白狀態格。
- **語意狀態**：固定於條目第二列最右的高對比膠囊，例如草稿、已完成、未連接、施工項目數或未填寫；完成用綠色、需處理用琥珀色、中性分類用灰色。
- **頁籤數量**：頁籤名稱旁的筆數，包含尚未儲存的進料與聯絡事項草稿。
- **可復原刪除**：左滑達門檻並放開後的延遲刪除，最新一筆可在 6 秒內復原。
- **水位量測摘要**：水位歷史的 60px 收合列，顯示量測時間、有效井位數與完整／缺值狀態。
- **水位輸出抽屜**：水位主頁底部可收合的最近三天文字輸出與複製操作。
- **跨模組呈現契約**：日報與水位共用的 UI 骨架；不代表資料模型或資料庫共用。
- **工種管理摘要列**：設定中的固定高度工種列；可全域搜尋工種與工項，右滑進入頁內編輯、左滑依影響摘要確認刪除。
- **設定區域導覽**：設定頁面內的四個區域連結，永遠維持在 `#settings/*`，不直接進入日報或水位填報。
- **進料接線盤**：只用於呈現與操作獨立進料至工種的一對一關聯；借用節點與端口的視覺語言，但不等同自由縮放的流程圖畫布。
- **關聯曲線**：接線盤中由進料端口通往工種端口的非互動 SVG 曲線；只呈現現有關聯，不接收點擊、拖曳或其他關聯命令。
- **工種端口關聯數**：匯入同一工種端口的獨立進料筆數；只是呈現彙總，不代表單筆進料可連接多個工種。
- **改接**：將已連接的獨立進料由原工種移至另一個工種；同一時間仍只能有一個目標工種。
- **原子化解除**：獨立進料轉為普通進料時，同一操作內清除連接並同步編輯器與目前草稿，不留下可被舊副本寫回的關聯。
- **連接異動**：連接、解除或改接進料的操作；因為會改變輸出內容，原工種與／或新工種必須退回草稿。
- **連接復原**：解除進料連接後 6 秒內恢復原工種關聯的操作；不適用於「轉為普通進料」的類型轉換。
