# 詞彙表

- **草稿**：唯一可編輯的目前日報，保存在 `live_report_draft`。
- **未完成（介面狀態）**：工程資料列對 `draft` 的使用者文字；只改變摘要顯示，不建立新的領域狀態。
- **定稿快照**：日報定稿時建立的不可回寫副本，含輸出文字與模板版本。
- **記憶**：供下一次填報建議使用的主檔資料，不是歷史日報內容。
- **候選記憶**：由現場輸入自動學習、尚未審核的資料；不出現在一般建議清單。
- **正式主檔**：人工新增或已確認的記憶，可作為下一次填報建議。
- **記憶審核**：確認候選為正式主檔，或逐筆駁回並依關聯規則處理目前草稿的流程。
- **材料主檔**：材料類型與候選欄位的可重用資料。
- **獨立進料**：必須連接至一張有效施工卡，並隨其輸出工種群組進入編號模式的進料原始記錄；未連結時不得進入正式日報。
- **連接進料**：仍由獨立進料持有、但在指定工種輸出的進料。
- **官方模板**：目前唯一版本化的日報文字輸出規則。
- **收合摘要（舊呈現）**：ADR-003 定義的固定 60px 資訊列；日報條目將由 ADR-008 的日報資料列取代，資料與展開行為不變。
- **條目摘要（舊呈現）**：ADR-003 定義的灰色類型區、兩列內容與狀態膠囊卡面；不再作為日報頁籤的目標視覺。
- **日報資料列**：ADR-008 定義的日報重複資料呈現單位；桌面使用對齊欄位，手機重排為三層，點擊後在原位置展開既有編輯內容。
- **代表工項摘要**：工程資料列收合時顯示的第一個非空白工項；若同一工種仍有其他非空白工項，後接「另 N 項」。位置不進入此摘要。
- **語意狀態**：草稿、已完成、未連接或未填寫等操作狀態；日報以文字、細色線或小型標記呈現，不配置大型固定膠囊格位。
- **進料關聯工作區**：進料頁中按需展開的完整接線盤；收合只隱藏工具，不改變任何進料連接或草稿資料。
- **日報預覽 Bottom Sheet**：具有遮罩、標題、關閉與焦點管理的日報預覽工作面板；開關面板屬於暫時 UI 狀態，不得造成 dirty 或保存。
- **頁籤數量**：頁籤名稱旁的筆數，包含尚未儲存的進料與聯絡事項草稿。
- **可復原刪除**：左滑達門檻並放開後的延遲刪除，最新一筆可在 6 秒內復原。
- **水位量測摘要**：水位歷史的 60px 收合列，顯示量測時間、有效井位數與完整／缺值狀態。
- **水位輸出抽屜**：水位主頁底部可收合的最近三天文字輸出與複製操作。
- **跨模組呈現契約**：日報與水位共用的 UI 骨架；不代表資料模型或資料庫共用。
- **工種管理摘要列**：設定中的固定高度工種列；可全域搜尋工種與工項，右滑進入頁內編輯、左滑依影響摘要確認刪除。
- **設定區域導覽**：設定頁面內的四個區域連結，永遠維持在 `#settings/*`，不直接進入日報或水位填報。
- **進料接線盤**：只用於呈現與操作獨立進料至工種的一對一關聯；借用節點與端口的視覺語言，但不等同自由縮放的流程圖畫布。
- **關聯曲線**：接線盤中由進料端口通往工種端口的非互動 SVG 曲線；只呈現現有關聯，不接收點擊、拖曳或其他關聯命令。
- **工種端口關聯數**：匯入同一工種端口的獨立進料筆數；只是呈現彙總，不代表單筆進料可連接多個工種。
- **改接**：將已連接的獨立進料由原工種移至另一個工種；同一時間仍只能有一個目標工種。
- **原子化解除**：獨立進料轉為普通進料時，同一操作內清除連接並同步編輯器與目前草稿，不留下可被舊副本寫回的關聯。
- **連接異動**：連接、解除或改接進料的操作；因為會改變輸出內容，原工種與／或新工種必須退回草稿。
- **連接復原**：解除進料連接後 6 秒內恢復原工種關聯的操作；不適用於「轉為普通進料」的類型轉換。
- **位置資料存在**：工項的起始樓層、結束樓層或位置文字至少一欄具有有效內容；位置編輯器是否展開不屬於位置資料。
- **工項輔助編輯器**：工項下方按需展開的位置或備註編輯區；展開狀態只屬於 UI，不是日報資料或儲存邊界。
- **工項低密度容器**：以極淡底色、圓角與留白辨識單筆工項的呈現單位；取代逐筆固定分隔線，不改變工項資料或輸出。
- **工項排序控制**：工項左側拖曳把手，以及等效的上移／下移可存取操作；只在同一施工卡內重排 `WorkItem.sortOrder`。
- **有效施工工項**：具有非空白施工內容的工項；位置完全不參與有效性判斷。
- **有效施工廠商**：具有有效施工工項，且符合施工人數規則的廠商施工卡；其精確人數邊界由 ADR-007 確認。
- **輸出工種群組**：日報文字中共用一個工種標題的施工廠商與連結獨立進料集合；這是 formatter 的呈現聚合，不改變進料仍由指定施工卡持有的關聯。
- **編號模式**：輸出工種群組含有至少一筆連結獨立進料時使用的格式；施工填報共同屬於第 1 項，每筆獨立進料各自取得後續編號。
- **純進料工種**：只有進料、沒有有效施工廠商的工種狀態；本系統不將其視為可完成或可定稿的日報內容。
