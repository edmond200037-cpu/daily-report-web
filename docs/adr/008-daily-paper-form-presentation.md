# ADR-008：日報紙本資料列與預覽工作面板

## 狀態

已接受；待分期實作。

## 背景

現行日報依 ADR-003 使用固定 60px 摘要卡、灰色類型區與狀態膠囊。實機檢視確認功能可用且沒有水平溢出，但大量同形卡片弱化了資料層級，也讓介面接近通用 AI／SaaS 後台。手機展開日報預覽時，固定面板約佔 45% 視窗高度並遮住後方內容。進料頁即使沒有資料，也會常駐完整關聯工具，增加空白流程負擔。

本決策只重整施工日報的呈現與暫時 UI 狀態，不改變任何領域資料或輸出契約。

## 決策

### 日報視覺方向

- 工程、進料、聯絡與特殊事項維持既有頁籤與資料分類。
- 四個頁籤共同改採紙本日報語言：暖灰紙面、炭黑文字、細灰欄線與節制的施工橘。
- 移除不增加任務資訊的英文眉標、裝飾漸層、陰影與大型狀態膠囊。
- 施工橘只用於新增、主要操作、施工中或需注意狀態。

### 條目由摘要卡改為資料列

- ADR-003 的「固定 60px 條目摘要卡」不再是日報條目的必要呈現。
- 桌面工程列採四欄；手機採三層響應式排列。
- 工程、進料、聯絡與特殊事項共用資料列骨架，但各自保留領域內容與操作。
- 點擊資料列在原位置展開既有編輯內容；展開不建立新提交邊界。
- 狀態以文字、細色線或小型標記呈現，不保留大型膠囊所占的固定格位。
- 拖曳、左滑刪除、可復原刪除及鍵盤替代操作不得退化。

### 進料關聯採漸進揭露

- 進料頁預設呈現進料清單與「管理工程關聯」入口。
- ADR-006 的完整接線盤改為按需展開；展開後仍遵守全部關聯基數、改接、解除、復原、搜尋與 IME 契約。
- 收合接線盤不得改變關聯、草稿狀態、輸出內容或資料保存。

### 預覽改為標準 Bottom Sheet

- 日報預覽收合時保留精簡操作列。
- 展開後必須具有遮罩、標題、關閉按鈕、焦點管理與獨立捲動區。
- 手機不得讓展開面板與後方頁面同時接收操作；桌面可使用窄型底部或側向工作面板。
- 空白或不可複製狀態不顯示有效樣式的複製命令。
- 開關預覽只屬於 UI 狀態，不得造成 dirty、更新 `updatedAt` 或排程保存。

## 功能不變量

1. 不變更 IndexedDB schema、日報型別、備份格式、formatter 與定稿快照。
2. 不改變工程、工項、普通進料、獨立進料、聯絡事項與特殊事項的資料所有權。
3. 不改變 ADR-006 的進料連接基數與狀態失效規則。
4. 不改變 ADR-007 的位置、備註、排序、草稿／完成與輸出群組規則。
5. 展開資料列、關聯工作區或 Bottom Sheet 都是暫時 UI 狀態，不得持久化至日報資料。
6. 中文輸入法組字、焦點、手機觸控與既有可存取替代操作不得退化。

## 與既有 ADR 的關係

- **ADR-003**：取代日報固定 60px 摘要卡、灰色類型區與大型狀態膠囊的視覺要求；保留共用骨架、展開、拖曳與刪除行為。
- **ADR-004**：第一階段只修改日報。跨模組的資料邊界仍有效；水位是否採用相同視覺語言須另立決策，不在本次同步修改。
- **ADR-006**：只把接線盤入口改為按需展開；所有連接模型與展開後的互動契約保持有效。
- **ADR-007**：所有資料、dirty、輔助編輯器與 formatter 決策保持有效。工程條目外層改為資料列，不等同改寫內層 `WorkItem` 契約。

## 後果

- 同一日報頁內不再混用舊卡片與新資料列；四個頁籤必須在同一階段完成視覺統整。
- 需要補齊 populated fixtures，因空白瀏覽器狀態不足以驗證長文字、多筆工程、拖曳及多曲線關聯。
- 現有依賴 60px 卡片的呈現測試必須改寫為語意、操作與資料不變量測試，不得單純刪除保護。
- 水位與設定中心維持現況，避免第一階段擴大回歸範圍。
