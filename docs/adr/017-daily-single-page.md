# ADR-017：日報分類改為一頁到底

- 日期：2026-11-21
- 狀態：採用
- 取代：ADR-008 中「保留四個分類頁籤」的部分；其他決策維持。

## 背景

日報原本從頁首到第一個新增動作有六層，手機首屏的施工入口約在螢幕七成高度。切換分類還會擷取暫存工項、要求放棄進料草稿，並使聯絡草稿阻擋複製與定稿，增加輸入錯誤與中斷。

## 決策

施工紀錄、進料、聯絡事項、特殊事項依序呈現在同一頁。每區以全寬新增列辨識，不再顯示分類頁籤、重複區段標題與空清單說明；施工入口保留施工橘。進料接線盤維持原功能。

日期與工地收進頁首按鈕，沿用 `toggle-basics` 與 `dailyBasicsExpanded`。預設收合，展開才渲染原基本資料欄位；檢視者仍可切換日期。開關面板只改 UI 狀態，不更新日報、不觸發保存或 mutation。

補正施工欄位、新增進料與管理連接改為捲動並聚焦，使用立即捲動以尊重減少動態偏好。跨區操作保留施工輸入與各區原有草稿；同區切換未儲存的另一筆仍保留確認。

## 後果與邊界

`DailyReportV3.activeTab` 與控制器 `switchTab` 保留相容性，但日報 UI 不再讀寫或呼叫；不升級資料庫、不變更資料模型、備份、formatter、驗證、定稿、記憶或同步。模組頁籤、設定、水位頁與底部預覽定稿流程維持原狀。

驗證涵蓋來源契約、既有單元測試、兩種 BASE_PATH 建置與本機瀏覽器手機寬度。這些檢查不代表正式部署、真實手機 IME 或共用模式 Realtime 已驗收。
