# ADR-010：工程拖曳預覽與原列一致

## 狀態

已接受。

## 背景

工程拖曳預覽掛在 `document.body`，離開 `.daily-page` 後失去紙本日報的 scoped 樣式；預覽也沒有使用原本的 `daily-entry` 外層。因此拖曳中的半透明列與靜止工程列不一致。

## 決策

- 拖曳預覽以 `tradeDragPreview()` 輸出日報 scoped wrapper 與完整收合工程列結構。
- 預覽沿用工種、代表工項、廠商／人數與狀態四欄；手機時自動沿用三層重排。
- 即使從展開中的工程條目開始拖曳，預覽高度仍鎖定為收合摘要列加上資料列邊線，避免留下展開編輯器的空白區。
- 預覽只以 `0.88` 不透明度與低高度、短模糊的柔和陰影表示暫時移動，不使用刪除紅底或另一套卡片視覺。
- 原位置的虛擬框保留相同資料列 DOM 與尺寸，以較低不透明度和虛線表示插槽，且標記為 `aria-hidden`。

## 不變量

- 拖曳仍只在排序完成時更新 `sortOrder`、草稿狀態與保存。
- 取消、Escape、pointer cancel 與左滑刪除互斥規則不變。
- 預覽與虛擬框不得變更 IndexedDB、formatter、輸出或定稿快照。
