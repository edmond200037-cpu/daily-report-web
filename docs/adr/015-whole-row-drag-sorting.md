# ADR-015：資料列整列長按排序

## 狀態

已接受。取代 ADR-010 中「以工程握把啟動拖曳」的部分；預覽與虛擬框的一致性規則沿用並擴及四類資料列。

## 背景

工程列左側的握把按鈕佔用一欄寬度，且只有施工紀錄能排序；進料、聯絡事項、特殊事項無法調整順序。握把也讓四類收合列的骨架不一致。

## 決策

- 移除工程列握把按鈕，四類收合列（施工紀錄、進料、聯絡事項、特殊事項）都使用無握把欄的相同骨架。
- 拖曳來源是已儲存、未展開列的 `.trade-row-summary__toggle`；尚未儲存的進料／聯絡草稿、展開或編輯中的列、唯讀工地、其他拖曳或左滑進行中時不可拖曳。
- 觸控與筆：按住 400ms 且位移小於 8px 啟動並震動 10ms；400ms 前位移達 8px 即取消，交還原生垂直捲動與左滑刪除。短按仍是展開。滑鼠：垂直為主且位移達 6px 啟動，水平移動仍是左滑刪除。
- 啟動時取消進行中的左滑並抑制接續的 click；拖曳中以非 passive `touchmove` 阻止頁面捲動，保留邊緣自動捲動。列保持 `touch-action: pan-y`，並以 `-webkit-touch-callout: none`、`user-select: none` 避免 iOS 長按選單與選字。
- 四類共用同一組拖曳狀態（以 `kind` 區分）與 `data-sortable-entry`／`data-entry-id`；插槽只計算同類列。放開時依 id 重排對應集合並重寫 `sortOrder`；只有施工紀錄同時維持既有的「退回草稿」。儲存失敗時還原順序並提示。
- ADR-010 的預覽一致性擴及四類：預覽複製被拖曳列的收合摘要，置於 `.daily-page` scoped wrapper，移除 id 與 data 屬性；原位置虛擬框保留相同 DOM 與尺寸、虛線、`aria-hidden`。

## 不變量

- 沒有鍵盤替代（與 ADR-007 已接受的限制相同；握把時期同樣沒有）。
- 工項編輯器內的工項握把、聯絡工項拖曳、設定頁工種左滑、進料連接面板不受影響。
- 拖曳只在放開並真的改變順序時更新資料；Escape、pointer cancel 取消且不改資料。
- 不變更資料模型、備份格式、formatter、驗證規則或定稿快照；同步沿用既有穩定 id 的 order mutation。
