# ADR-013：工地共用資料與離線同步

日期：2026-09-21  
狀態：規劃提案，尚未實作。使用者已確認多人同工地與跨裝置需求；具體技術方案依實作計畫推進。

## 背景

ADR-001 將產品限制為無帳號、無後端、無多人同步。新增需求需要共用記憶、當日施工日報草稿與水位，因此未來共享模式必須調整資料所有權；現行本機模式在遷移前保持不變。

## 決策

- GitHub Pages 繼續部署 PWA；Supabase 提供 Auth、PostgreSQL 與受權限保護的資料介面。
- 以工地為授權與資料隔離邊界，每人獨立登入；owner、editor、viewer 由資料庫權限強制執行。
- 雲端已提交版本是共享資料權威，本機 IndexedDB 保存快取與尚未同步的操作；離線保存不代表其他裝置已取得。
- 所有共享寫入使用具版本比對與冪等保證的交易路徑。第一版整份草稿遇版本衝突需人工處理，不靜默覆蓋。
- 延續 ADR-011 的定稿保留草稿、不可變快照、內容指紋去重、候選三次確認與白名單；將原子提交移到服務端，指紋作用域改為工地與草稿。
- 本機資料清理與雲端刪除分開。既有七日／三日範圍不得直接套用為雲端保留政策。
- 初次遷移保留舊 IndexedDB 與完整備份；先試用單一工地，再擴大使用。

## 影響

共享模式啟用後，本 ADR 取代 ADR-001 中「無帳號、無後端、無多人同步」及唯一全域草稿的限制；不提前宣告現行功能已切換。ADR-011 的產品語義持續有效。

新增同步、權限與完整備份維護成本；免費方案有配額與服務暫停限制。未同步資料需明確提示，不能以本機寫入成功當作雲端成功。
