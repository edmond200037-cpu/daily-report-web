# ADR-005：記憶生命週期與統一設定中心

## 決策

設定入口統一為 `#settings`，分為施工日報主檔、水位設定、記憶審核與資料／系統。現場自動學習的名稱與材料欄位一律先為候選；人工新增、審核確認，或符合 ADR-011 的三次定稿自動確認門檻後，才成為一般建議使用的正式主檔。

## 後果

- 舊設定網址導向對應的統一設定中心頁面。
- 候選依資料類型分區，可在單一分區內批次確認。草稿影響為 0 筆的候選可批次駁回；任何會影響目前草稿的候選仍必須逐筆顯示影響並二次確認。
- 候選列預設採單行摘要，只呈現選取、名稱、類型與定稿使用進度；父層關係、最近使用與草稿影響按需展開。
- 記憶審核以手風琴呈現資料類型，同一時間只展開一個分區；區內先依定稿使用進度由高到低，再依最近使用時間排序。
- 分區預設不選取候選，提供「全選本區」；選取後由固定底部操作列統一確認或駁回。
- 批次確認直接完成，不再增加確認對話框。草稿影響為 0 筆的批次駁回只確認一次；會影響草稿的逐筆駁回仍維持影響摘要與二次確認。
- 選取廠商、工項或材料欄位候選時，若其必要父層仍為候選，系統必須自動連帶選取父層，並在固定操作列揭露額外包含的必要資料；不得建立已確認但父層仍不可用的孤立記憶。
- 頁面預設展開具有最高優先候選的非空分區。批次處理後立即移除已完成列並顯示結果；分區清空後自動展開下一個非空分區。
- 記憶審核只處理標準化後的精確重複，不在此流程加入模糊名稱比對、自動合併或相似名稱決策；相似記憶整理屬於另一個工作流程。
- 候選在未達自動確認門檻前，不得出現在自動填入或一般建議清單；仍可由記憶審核提前確認。
- 駁回或刪除只會修改目前草稿；定稿快照、水位歷史與記憶備份邊界維持不變。
- 工種管理使用獨立新增表單與跨工種／工項搜尋；工種摘要列右滑編輯、左滑刪除，刪除前必須列出主檔與目前草稿影響並二次確認。
- `#settings/*` 內只能以設定區域導覽互相切換；填報模組頁籤只出現在 `#daily` 與 `#water-level`。
