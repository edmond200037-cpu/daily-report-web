# ADR-018：日報新增工具列

日期：2026-11-24，已採用（使用者決定）。

以頁籤下方的一列黏頂工具列，取代 ADR-017 的區段上方新增按鈕；四個動作沿用原事件名稱，手機顯示短標籤並提供完整 aria-label。區段以間距與 2px 分隔線區分，不新增卡片或陰影。

標亮只代表捲動位置：以工具列底部為界，最後越過該界線的區段為當前段；第一段尚未越線時仍以施工段為預設。當前按鈕以施工橘底白字及 aria-current 標示，取消施工新增按鈕常駐橘色，避免把動作種類誤認為目前位置。

標亮由獨立 UI 模組以單一 passive scroll 監聽、requestAnimationFrame 節流，重新渲染後立即同步，只修改 DOM 屬性，不寫入 appState、草稿或 mutation。區段保留工具列高度的捲動餘裕，新增編輯器捲入視窗並聚焦；使用即時捲動，亦符合減少動態偏好。工項選單開啟時降低工具列圖層，讓選項可操作。
