# 逐筆新增操作流程規劃

> 後續修正：使用者要求手機操作優先，位置／樓層、備註、移除維持隱藏。本文中展開附加欄位等建議已撤回；最新實測與規劃以 [手機重新操作結果](../mobile-recheck-2026-10-04/review.md) 為準。

依據：2026-10-04 實測，以及使用者明確指定以逐筆輸入、操作順序與新增順暢度為核心。以下為規劃，尚未修改應用程式。

## 設計主線

確認工地／日期 → 新增施工紀錄 → 選工種 → 確認廠商 → 輸入人數 → 連續加入工項 → 完成這筆或完成並新增 → 聯絡事項 → 檢查日報。

填報過程不要求使用者先進設定建立主檔。查無工種、廠商或工項時，直接使用輸入文字，完成後再依既有規則建立候選記憶。

## 施工紀錄：操作與畫面反應

| 步驟 | 使用者操作 | 系統反應與下一個位置 | 防止中斷 |
|---|---|---|---|
| 1 | 確認工地與日期 | 編輯單筆時保留精簡摘要 | 日期資料尚未載入時不允許新增到前一天的資料 |
| 2 | 點新增施工紀錄 | 開啟工種選擇器：最近／常用、搜尋、使用新名稱 | 此時不產生空白紀錄；取消直接返回 |
| 3 | 選土方工程 | 開啟同一張編輯卡；顯示可更換的最近廠商日盛興 | 不跳入設定；不以歷史資料預填本日人數或工項 |
| 4 | 確認廠商、輸入 4 人 | 廠商正確時直接往人數，再往工項 | 手機人數使用數字鍵盤；自動帶入必須清楚可見 |
| 5 | 選／輸入土方開挖 | 點常用項目即加入；自由輸入按加入或非組字狀態的 Enter | 新增後清空輸入框，焦點保留；剛加項目可見、可撤銷 |
| 6 | 補樓層、出土量或備註 | 在該工項內按需展開 | 可先用既有欄位承接；不為了欄位化強迫每筆經過多個畫面 |
| 7A | 點完成這筆 | 必填通過後收合，顯示工種／廠商／人數／工項摘要 | 缺漏時保留表單並定位第一個錯誤；可保留未完成草稿 |
| 7B | 點完成並新增 | 完成並收合前筆，立即打開與步驟 2 相同的工種選擇器 | 取消下一筆不撤銷前筆，不留下空白卡片 |
| 8 | 點已完成卡片 | 原位置展開修改；完成後回到該卡片 | 不跳頁頂，不改變紀錄順序 |

一般輸入自動存本機草稿；「完成」表示完成這筆的檢查與收合，不是唯一保存時點。雲端同步在背景執行，失敗顯示狀態但不鎖住下一筆輸入。

## 同一筆連續加工項

連續壁案例：選連續壁 → 確認安暉 → 輸入 1 → 點預留筋打出 → 點扶壁打除 → 完成並新增。

雜工案例：選雜工 → 確認藝境 → 輸入 1 → 逐項點選常用工作 → 輸入尚未建立的新工項 → 完成這筆。

- 常用工項保留在同一區域，加入一項不關閉整個選擇區。
- 已加入項目有明確狀態，避免無意重複；相同名稱若有不同樓層或位置，仍可明確選擇再加一項。
- 剛加入項目提供撤銷，桌面與手機均有可見的編輯／移除入口，不只依賴左滑與長按。
- 若工項輸入框還有尚未加入的文字，點完成時應一併納入再驗證；若資料無效則提示，不能靜默丟棄。
- 切分類或返回列表保留編輯草稿；背景同步與候選更新不得替換正在輸入的元素。

## 聯絡事項：沿用相同新增節奏

新增聯絡事項 → 選工種 → 確認／輸入廠商 → 預定日期（選填）→ 加入工作內容 → 完成這筆／完成並新增。

以鷹架為例：鷹架工程 → 元昌 → 10/05 → 上下設備施作 → 完成並新增 → 植筋工程。

- 工種、廠商、工項使用與施工紀錄相同的選擇規則。
- 無預定日期的純聯絡內容仍可完成，不強迫填日期。
- 下一筆可顯示「沿用上筆 10/05」快捷選項，只有點選才帶入；不可默默沿用，因後續日期會變成 10/06、10/07。
- 數量與規格為選填展開區，主要路徑維持簡短。
- 新增與編輯都保留草稿；「取消新增」與「放棄修改」分清楚，有內容時提供保留草稿的退出方式。

## 實作順序

1. 修正「完成並新增」繞過工種選擇器的問題，以及取消後空白資料的生命週期。
2. 穩定工項連續加入：不跳焦點、不整頁重繪、不丟尚未加入文字；支援常用點選與自由輸入。
3. 統一施工／聯絡的完成、下一筆、取消、返回修改行為。
4. 整理欄位與快捷選項：廠商帶入、人數鍵盤、選填日期與附加資訊。
5. 修正預覽遮擋，顯示施工筆數、人數、聯絡筆數及尚未完成筆數。

同步 RPC 與誤導狀態屬資料可靠性問題，仍須優先處理；與上述新增流程使用獨立工作包，不讓表單 UX 改造等待完整資料模型重建。

## 模組與驗收

建議由 `entry-workflow` 管理 picking／editing／complete 狀態；施工與聯絡共用選擇器及完成列，各自保留欄位元件。保存服務、記憶候選與同步狀態分離，沿用穩定資料 ID。

驗收以本次三筆施工加五笔聯絡案例，採真人逐字輸入與常用項目選取：

- 完成並新增永遠回到相同工種選擇器。
- 工種選擇器取消後沒有新空白紀錄，前一筆仍保留。
- 一筆連續加入六項時，位置與焦點穩定，已加入項目不遺失。
- 修改中文句子中間的字後，游標留在修改處；中文選字 Enter 不誤觸加入或完成。
- 未按加入就按完成、切分類後返回、儲存中退出編輯均不靜默丟字。
- 欄位缺漏只在適當時機提示；資料保存錯誤立刻顯示。
- 手機鍵盤不遮住目前欄位與主要操作，亦不任意彈出／收起。
- 同步延遲或失敗時仍能新增，清楚區分本機保存與雲端確認。

記錄每筆點擊次數、重打次數、鍵盤切換次數與完成時間，改善前後以相同案例比較；不將自動化填入時間當作真人操作效率。
