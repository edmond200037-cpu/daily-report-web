# 聯絡事項 UI 對齊施工紀錄

- 收合摘要沿用施工紀錄的欄位、字體、狀態色與手機兩層版面。
- 編輯器沿用工種收合列、編輯工種入口、廠商欄位、工項列及完成操作區。
- 工項沿用共用手勢模組：長按排序、插入線、左滑刪除、復原、Delete 鍵操作。
- 聯絡事項保留預定日期、數量／規格及取消草稿；資料結構與既有日期輸出維持相容。
- 新增聯絡草稿不再顯示整筆刪除滑動底板；文字修改立即保留輸入草稿。

## 功能差異

聯絡事項沒有施工紀錄的人數、位置／樓層與備註欄位，這些資料無法直接互換；保留聯絡事項的日期與規格欄位。工項握把的點擊位置／備註選單因此僅屬施工紀錄。聯絡事項收合列左側為展開提示，沒有新增整筆聯絡事項拖曳排序。
