# ADR-014：現行記憶、共享與定稿邊界

日期：2026-10-05。此文件整理現行行為，取代 ADR-001／005／011／013 與舊計畫中的無帳號、定稿學習、三次確認描述。

- 本機模式使用 IndexedDB；登入並選工地後使用分區資料、Supabase 權限與 outbox 同步。
- 記憶依有效套用事件去重累計，第 4 次自動確認；人工確認仍可提前進行。規則與實作見 [輸入流程](../input-workflow-2026-09-30.md) 及 `src/settings/memory-applications.ts`。
- 定稿建立本機不可變快照並保留當日草稿；後續設定修改不得回寫歷史。定稿快照的雲端跨裝置歷史並未由此次修復新增。
- 同步有背景排程、Realtime 提示與手動入口。尚未成功送出的操作與衝突必須保存，解決衝突前永久備份原始來源。
- 水位的近三天範圍是顯示篩選，只有使用者明確刪除才產生共享刪除；較舊量測保留作為變化量基準。

本機測試、隔離 PostgreSQL、正式 Supabase、手機與部署驗收分開記錄。此次修復證據見 [修復紀錄](../full-repository-audit-fixes-2026-10-05.md)。
