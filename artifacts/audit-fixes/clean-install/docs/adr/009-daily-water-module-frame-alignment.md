# ADR-009：施工日報與水位變化共用模組框架

## 狀態

已接受。

## 背景

ADR-008 把施工日報改為紙本工作表，但水位變化仍保留舊的通用頁首與英文輔助文字。兩個同層級工作流切換時，設定入口、頁籤留白與文字層級不一致，增加現場辨識成本。

## 決策

- `#daily` 與 `#water-level` 使用共用的 `module-page`、`module-page__header` 與 `module-page__tabs` 骨架。
- 兩頁共用暖灰紙面、頁首欄線、設定按鈕與雙主頁籤節奏。
- 日報維持可變的本機儲存狀態；水位以「本機量測資料」佔用同一輔助文字位置。
- 日報目前頁籤使用施工橘；水位目前頁籤使用量測綠。這些色彩只代表所在工作流，不改變資料狀態。
- 本次不改寫水位輸入、歷史、匯入、井位設定、資料模型或儲存行為。

## 後果

- 兩個主工作流在切換時具有相同的閱讀起點與操作密度。
- 日報工程列的淡紅「未完成」格與內縮左右界線仍屬 ADR-008，與水位框架對齊無關。
- 後續若要重整水位內容資料列，必須另行評估，不得藉本 ADR 擴大範圍。
