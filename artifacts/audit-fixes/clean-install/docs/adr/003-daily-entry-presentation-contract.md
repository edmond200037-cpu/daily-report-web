# ADR-003：日報條目共用呈現契約

## 決策

工程條目、進料、聯絡事項與特殊事項共用相同的頁面骨架與 60px 條目摘要：固定灰色類型區、左對齊兩列內容區與固定在第二列最右的語意狀態膠囊。三者是語意分區，但視覺上僅為左側類型區加上一張連續卡面；狀態不得另形成空白格或第三個面板。填報資訊與底部日報預覽同樣使用 60px 收合摘要列。進料摘要必須佔滿條目卡片寬度，不得使用桌面雙欄 layout。工程拖曳區將圖示與「工程」橫向排列，拖曳佔位高度等於收合摘要。展開與左滑刪除維持各領域既有行為。

## 後果

- 呈現層以單一摘要高度 token 共同調整觸控高度、間距、滑刪底層、展開狀態與完成／警示／中性狀態色彩。
- 工程拖曳把手保留於固定類型區，不影響其他條目的文字對齊。
- IndexedDB、日報型別、備份契約與 formatter 不因視覺一致化而變更。
