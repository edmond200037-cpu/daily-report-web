# ADR-012：設定端直達導覽

設定端不再使用「設定中心」作為中繼頁。日報與水位的設定入口直接連至所屬設定區；四個設定區由同一組頁首設定主導覽切換，頁首主操作依來源返回日報或水位，以縮短現場填報回程。此決策只取代 ADR-005 的設定導覽部分；記憶生命週期、候選審核與資料邊界仍維持 ADR-005。

## 後果

- `#settings` 不再是一般導覽停靠點；舊網址應導向可判定的設定區或日報，而非要求使用者再選一次。
- 施工日報主檔依工作目的分為「施工基礎」與「材料與文字」兩組，先以兩張入口卡呈現，同一時間只展開一組且預設施工基礎；這是暫態 UI。四個設定主導覽維持 2×2 框線按鈕，但其視覺權重低於目前工作面。
- 設定返回來源跨四個設定區持續保留；直接開啟設定網址時預設返回日報。
- 設定工作面卡展開後，以直列管理清單開啟既有管理內容；不再使用第二層按鈕矩陣。設定主導覽的未選中項目為白底細灰線，選中項目維持白底、以深色文字與底部橘線標示。
- 舊 `#settings` 直接導向 `#settings/daily`。
- 記憶備份、還原與偵錯只屬於全域「資料與系統」；日報主檔不建立重複的「系統」工作面。管理內容在其工作面卡下方原地展開，管理清單維持可見並標示目前項目。
- 工作面與管理項目不寫入網址；`#settings/daily` 重整後回到預設的施工基礎工作面，以避免路由、返回來源與未儲存編輯狀態交錯。
