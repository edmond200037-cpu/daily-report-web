> 後續修正：附加欄位已改由握把短按的半輪盤開啟，整列左滑已調整。最新證據請見 `../mobile-gestures-2026-10-04/review.md`。

## 本次範圍

依照手機重測回饋修正本機版本；維持原紙感、橘色主操作與資料格式。未部署正式網站或資料庫。

## 已實作

1. 工項位置／樓層、備註、移除工具列與附加內容保持隱藏；原資料與格式器保留。左滑刪除、長按排序沿用既有實作，握把補上 Delete 的鍵盤替代操作與可復原提示。
2. 工種搜尋只更新建議與操作區，不重建輸入框；清除保持同一輸入框。
3. 編輯施工卡只顯示工種與返回，工種名稱可點「變更」；廠商／人數兩欄，避免三欄擠壓與舊摘要狀態矛盾。
4. 單一工項加入框；推薦排除已加入工項後再取六筆，保留待審核工項可用性，但不顯示審核狀態。明確輸入同名仍可加入，原重複驗證保留。
5. 新增回饋為文字與短撤銷動作；撤銷最新加入不再走一般刪除確認，成功後回到輸入框；一般刪除若取消，不再只移除畫面。
6. 施工與聯絡事項底部都只保留「完成這筆／完成並新增」，主要操作為完成並新增；返回保留草稿，聯絡取消／放棄置於草稿選項。
7. 完成區使用底部 sticky 與安全區留白；主要輸入與完成按鈕至少 48px，聯絡欄位單欄；進入編輯先收合預覽，仍可明確點開。
8. 工項撤回與復原統一由 DailyController 處理，保留穩定 ID 與位置；復原不能跨日期或工地。沿用既有草稿、IndexedDB 與同步流程，不新增 API 或 LLM 呼叫。

## 靜態與自動測試

- TypeScript 通過。
- Vitest：40 個檔案、180 項測試通過。新增覆蓋推薦排除／工種隔離、穩定 ID 撤回、復原冪等與分區界線。
- Vite 與 PWA 正式打包通過，輸出保留於本目錄 `build/`。既有交付用 dist 與測試快取已還原，沒有部署。
- 自訂 outDir 的一般 CLI 遇到 Windows realpath EPERM；使用既有 preserveSymlinks 執行參數完成打包，未修改專案設定。
- 打包仍有原有大於 500 kB 的分包提示，與本次輸入修正分開處理。

## 驗證界線與歷程

- 原分頁曾受舊刪除確認阻擋；使用者回覆按了確定，已核對僅刪除本輪測試加入的同名項，原六項完整保留。新版撤銷與聯絡流程均已補驗。
- 本輪加入的同名測試項均已撤回或移除，最終重新載入核對原六工項。
- 真實手機的中文組字、螢幕鍵盤、觸控左滑與長按仍需實機驗收。桌面瀏覽器尺寸測試不等於實機通過。
- 雲端權限／離線／雙裝置與既有 RPC 問題不在本輪驗收內。
